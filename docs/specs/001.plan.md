# Plan — SPEC-001 (candidato)

> Siguiente SPEC tras el kit documental (Grupo A). Rama prevista: `cursor/spec-001`
> desde `develop` (inicializar git si aún no existe; ver [`PLANNING.md`](../../PLANNING.md) §0.7).

## Recomendación

**Una sola opción: scaffold.** Sin base técnica no hay hero, servicios ni case study.

## Alcance propuesto

1. Crear proyecto Astro (template minimal, TypeScript strict) **en este directorio**,
   sin pisar `docs/`, `AGENTS.md`, `public/design/` ni `src/assets/images/ruben-source.png`.
2. Tailwind CSS v4 con `@tailwindcss/vite`. Tokens `@theme` según
   [`DESIGN_SYSTEM.md`](../DESIGN_SYSTEM.md). **No** `tailwind.config.*` (D-013).
3. Scripts `dev`, `build`, `preview`, `check` (`astro check`). Node >= 22.12.
4. `src/layouts/BaseLayout.astro`: `lang="es"`, skip link, slot, import de `global.css`.
5. `src/pages/index.astro`: página vacía de marketing (título de documento + un heading
   de sistema), lista para que SPEC-003 monte el hero.
6. Fuentes autoalojadas (Newsreader + Source Sans 3, o fallbacks documentados).
7. `.gitignore` de Astro. No commitear `node_modules` ni `dist`.
8. Verificar `npm run check` y `npm run build`.
