## Objective

Que buscadores y redes identifiquen a una **persona** que ofrece desarrollo web en
España, no una consultora ni un negocio local con ciudad.

### Alcance

- `title`, `description`, canonical por página
- Open Graph + Twitter card; imagen OG de **fondo sólido** (papel), sin PNG con alfa
- `robots.txt` + `sitemap.xml` (sin paquete extra, D-004)
- JSON-LD `@graph`: `Person` + `ProfessionalService`
- `lang=es`, `og:locale=es_ES`

Excluye: blog, hreflang, `LocalBusiness`, `Organization` «consultora», analytics.

## Acceptance Criteria

- [x] `check`/`build` 0 errores

- [x] Schema sin LocalBusiness ni ciudad
- [x] OG con fondo sólido
